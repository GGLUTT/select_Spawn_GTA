## Деплой на живу сторінку (GitHub Pages)

- Передумови:
  - Має бути ініціалізований `git` та доданий віддалений репозиторій (GitHub):
    - `git init`
    - `git remote add origin <URL вашого GitHub репозиторію>`
  - Встановлений `npm` та `git` на вашій машині.

- Команда деплою:
  - `npm run deploy`

- Що робить команда:
  - Публікує статичні файли (`index.html`, стилі, скрипти та вміст папки `img/`) у гілку `gh-pages` вашого репозиторію.
  - URL буде мати вигляд `https://<ваш-юзернейм>.github.io/<назва-репозиторію>/`.

- Примітки:
  - Скрипт деплою виключає зайві файли та не деплоїть `node_modules`.
  - Якщо гілка `gh-pages` ще не існує — вона буде створена автоматично.
